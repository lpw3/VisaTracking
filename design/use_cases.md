## Use Cases

1. The Visa-Seeker 
- Calculate an estimated wait time for their specific visa based on historical data
- See changes in wait times to see stability of the estimate.
- See statistics on chances of approval.
- See any updates to visa criteria.
2. The Immigration Expert
User needs:
- View aggregate information across countries on a specific visa.
- Compare incoming population across countries and visa types.
- Filter by country, year, visa category, consular post or refusal reason
- Download data as CSV with citations for source data

Actions:
- Download data button 
    - Backend database with either pre-built datasets or active SQL pull from the database
- Choosing filters, filtering menu (countries, years, visa type, refusal reason)
    - Intuitive design to imply data availability
- Dynamic plotting tool
    - Ability to download created figure or backend data 
- Citations to original data source
    - Dataset comes with genertic citation to our database, point towards full list of citations and links to Department of State documents. 
- Non-English users 
    - Translations?

3. The Social Scientist
- Download data that has been compiled into CSV format from disparate data sources
- Access clear data source documentation
- Replicate existing code to add new data sources as needed
4. The Non-Expert Info Seeker
- Search for a keyword among all variables
- Visualize data in browser over time
- Contextualize data with policy or event changes on the chart that effect visa regulations
- Create custom filtered charts to export
